# Privacy Policy for FATE - Markdown Viewer

**Effective Date:** June 5, 2026

## 1. Data Collection
FATE (Formatted Article & Text Explorer) is a completely offline, local desktop application. We take your privacy seriously and believe your data belongs to you. 

* **No Telemetry:** FATE does not collect, store, or transmit any analytics, usage data, or crash reports.
* **No Cloud Processing:** All Markdown parsing and rendering is done entirely locally on your machine.
* **No Accounts Required:** FATE does not require you to create an account, log in, or provide any personal information.

## 2. File Access
FATE requests "Full Trust" (local file system access) solely for the purpose of opening and displaying the `.md` or `.markdown` files that you explicitly choose to open or drag into the application. We do not scan, index, upload, or share your files with any external servers. Your local files never leave your device.

## 3. GitHub Auto-Updates
FATE periodically checks the official GitHub repository to see if a newer version of the software is available. This is a standard network request to GitHub's servers and does not contain any personal data or file contents.

## 4. Contact
If you have any questions or concerns about this privacy policy, please open an issue on the official GitHub repository:
https://github.com/VagueDustin/FATE
