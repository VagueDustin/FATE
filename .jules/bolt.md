## 2026-06-20 - High-Frequency Scroll Optimization
**Learning:** In applications with complex rendered content (like Markdown with LaTeX), high-frequency events like scrolling can become a bottleneck if they trigger state updates or expensive DOM queries (like `querySelectorAll`) on every tick. Caching DOM elements in a `useRef` and throttling the handler with `requestAnimationFrame` prevents layout thrashing. Additionally, using `useRef` for tracking values that are only needed for logic (like `filePath` for window titles or `activeHeading` for comparison) avoids unnecessary React re-renders.
**Action:** Always cache expensive DOM queries that don't change frequently. Use `requestAnimationFrame` for throttling visual updates in scroll/resize handlers. Prefer `useRef` over `useState` for values that do not contribute to the rendered output.
