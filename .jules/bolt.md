## 2025-05-14 - [Scroll Performance & Ref Stability]
**Learning:** High-frequency events like 'scroll' can cause massive performance degradation if they trigger complex DOM queries (`querySelectorAll`) and React state updates in every frame. Furthermore, calling side-effects (like `processMarkdown`) inside a `setState` updater is an anti-pattern that can lead to inconsistent state and unnecessary re-renders.
**Action:** Use `requestAnimationFrame` to throttle scroll events. Cache DOM-heavy queries (like heading lists) in a `useRef` when the content changes, rather than querying on every scroll event. Maintain reference stability for heavy functions with `useCallback` and use `useRef` to track values needed by effects (like `filePath`) without including them in the dependency array, avoiding unnecessary effect re-executions.
